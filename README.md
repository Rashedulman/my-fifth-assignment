### Answer the following questions clearly:

1. What is the difference between **getElementById, getElementsByClassName, and querySelector / querySelectorAll**?
   Answer: The differences between getElementById, getElementsByClassName and querySelecto/ querySelectorAll are getElementById helps to find only one elemen by using id on the contrary getElementsByClassName helps to find multiple elements by using class name on the other hand querySelector helps to find the first element by using CSS selector whereas querySelectorAll helps to find all elements by using CSS selector.
2. How do you **create and insert a new element into the DOM**?
  Answer: I use createElement() function to create a new  element and I use append() function to insert the element into the Dom.
3. What is **Event Bubbling** and how does it work?
  Answer: Event Bubbling means an event starts from the inner element and moves to the outer elements. 
For example, click on a button event goes to button then div then body etc. 
4. What is **Event Delegation** in JavaScript? Why is it useful?
   Answer : Event Delegation means adding an event to a parent element to control child elements. 
It is useful because it uses less code and helps to handle many elements easily.
5. What is the difference between **preventDefault() and stopPropagation()** methods?
   Answer:preventDefault() function stops the default action of an element on the other hand stopPropagation() function stops the event from moving to parent elements.
